## Bandpey HQ

Shared engineering for Bandpey's products:

- [FACTHORY](https://github.com/FACTHORYAI): a multilingual AI assistant that captures
  expert knowledge and empowers the next generation of workers.
  [facthory.com](https://facthory.com)
- [Emolysis](https://github.com/emolysis): a local-first coding agent for data
  engineering and BI on Databricks, Snowflake and Microsoft Fabric.

This organization holds what the product organizations share: CI building blocks and
the configuration of the GitHub organizations themselves.
